## ✨ 機能

- 🎨 **ビジュアル編集** - 直感的なグラフィカルインターフェースでレベルをデザイン
- 🎮 **即座にテスト** - 内蔵NESエミュレータでリアルタイムにレベルをテスト
- 🔗 **レベル共有** - ワンクリックで共有リンクを生成
- 💾 **ROM編集** - ROMファイルを直接変更してエクスポート
- 🌐 **多言語対応** - 中国語/英語/日本語インターフェースをシームレスに切り替え
- 📋 **レベル管理** - ドラッグ＆ドロップでの並べ替え、一括編集
- 🛟 **独立バックアップ** - ROMアドレスに依存せず、単一ステージまたは全ステージを入出力
- 📦 **下書き・共有タブ** - 下書き、読み込み、共有ステージを独立編集し、正式一覧の末尾へ追加可能
- 📴 **無効ステージ保護** - ステージ数を減らしても末尾データを削除せず、灰色の無効状態で保持

## 📖 使用ガイド

### 1. ROMをアップロード

- 「📁 ROMファイル選択」ボタンをクリック
- 合法的に所有しているモアイくんROMファイル（.nes）を選択
- 読み込みが完了するまで待つ

### 2. レベルを編集

- 左側のサイドバーからレベルを選択
- 右側のツールバーでタイル/敵/特殊アイテムを選択
- 左クリックで配置、右クリックで削除
- シーン、ワイドスクリーン、その他のプロパティを調整

### 3. レベルをテスト

- 「🎮 ステージテスト」をクリックして、エミュレータで現在のレベルを実行
- 「🎮 ROMテスト」をクリックして、完全なゲームをテスト
- テスト・ダウンロードはすべて拡張 Mapper 2 ROM（PRG 128 KiB）を使用します。アップロード元のファイルは変更しません。
- 「上キーで視点切替」は初期状態でオフの実験機能です。オフでは単画面固定・横長画面ループ追従を維持します。オンでは単画面固定・横長画面の原版境界停止から開始し、プレイ中に上キーでループ追従へ切り替えます。切替は1フレーム最大4ピクセル。横長画面の一時停止中の左右閲覧は常に使用でき、単画面ではループ追従時のみ使用できます。コウモリの横方向ループもこの設定に従います。
- 原版の `START / CONTINUE` とパスワード機能を復元しました。ステージテストは `START` を選び、開始後に上キーで切り替えます。
- この設定がオンの場合、ステージ開始時と一時停止中の閲覧から戻るときも、1フレーム最大4ピクセルで滑らかに目標へ移動します。
- 閲覧後の再開は、カメラが戻るまでゲームとタイマーを一時停止し、到着後に自動で再開します。移動中のキー入力では途中解除されません。
- 「⏹️ エミュレータ停止」をクリックして、編集に戻る
- ショートカット：`F5` でステージをテスト、`F6` でエミュレータを停止、`Ctrl + S` でステージを保存します。ボタンが無効なときはショートカットも動作しません。

- エミュレータ実行中、`Shift + F1`～`Shift + F4` で4つの一時スロットにセーブし、`F1`～`F4` でロードできます。スロットは上書きできます。空のスロットはロードできません。
- モバイル版では「エミュレータメニュー」の操作リストからクイックセーブ、クイックロード、エミュレータ停止を操作します。メニュー表示中はゲームが一時停止し、閉じると再開します。F1 スロットを使用し、上書き、ロード、停止には確認が必要です。
- 「画面を戻す」を押すと、ゲームを再起動せずに画面を表示位置へ戻し、左右中央に配置します。
- エミュレータを停止するか別のROMを読み込むと、4つのスロットは消去されます。クイックセーブはROMやブラウザのストレージに保存されません。
- F1、F3、F4 はブラウザのショートカットでもあるため、キーの取得はブラウザやOSによって異なります。
- ゲームのセレクトキーは `Alt` で、`Shift + F1`～`Shift + F4` のクイックセーブとは別です。内蔵 jsnes は音声チップの状態を保存しないため、ロード直後の音声が一時的に途切れる場合があります。

### 4. 保存と共有

- 新しいブラウザキャッシュは、旧キャッシュを削除せずROM・ステージ・下書きを一度コピーします。ROM内部より新しい個別ステージキャッシュを優先します。
- 編集済みROMはバージョン記録と局所的なパッチ・配置の特徴で判定し、ファイル全体のハッシュは使用しません。互換性のある画像差替版も使用できます。新版・旧版の出力や版不明の拡張ROMを再読み込みした場合、赤い警告を表示したまま編集・テスト・エクスポートを継続できます。バージョン記録は再パッチの安全性を保証しません。
- 全ステージをバックアップしてから「未編集ROMに交換・ステージ保持」を使用してください。順序・数・敵・下書き・未保存の編集・設定を保持します。検証やキャッシュ保存に失敗しても、旧プロジェクトは保持されます。

- **💾 ステージ保存** - 変更をメモリに保存
- **📝 ROMに書き込み** - すべての変更をROMデータに書き込む
- **⬇️ ROMダウンロード** - 変更されたROMファイルをダウンロード
- **🔗 ステージ共有** - 共有リンクを生成し、友達にコピーして送信
- **📤 現在のステージを書き出す** - 未保存の変更を含む現在の編集を `.moailevel` で保存
- **🧰 全ステージを書き出す** - 正式ステージと下書きを `.moaipack` 復旧ファイルで保存
- **📥 ステージを読み込む** - 単一ステージは下書きへ、全ステージパックは正式ステージを復元
- **🧰 全下書きを書き出す** - 下書き・共有ステージを `.moaidrafts` で個別に保存
- **➕ 正式ステージに追加** - 有効ステージの末尾、灰色の無効ステージより前に下書きを挿入

## 🎮 重要な注意事項

**このツールは合法的なゲームROMファイルが必要です**

1. ✅ 自分の実物カートリッジからROMをダンプ
2. ✅ または公式/合法的なソースから購入
3. ❌ 違法なウェブサイトから海賊版ROMをダウンロードしないでください

## 🛠️ 技術スタック

- **フロントエンド**: バニラJavaScript (ES6+)
- **NESエミュレータ**: [JSNES](https://github.com/bfirsh/jsnes)
- **グラフィックス**: HTML5 Canvas
- **スタイリング**: CSS3
- **ビルドツール**: 不要、直接実行
