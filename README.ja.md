## ✨ 機能

- 🎨 **ビジュアル編集** - 直感的なグラフィカルインターフェースでレベルをデザイン
- 🎮 **即座にテスト** - 内蔵NESエミュレータでリアルタイムにレベルをテスト
- 🔗 **レベル共有** - ワンクリックで共有リンクを生成
- 💾 **ROM編集** - ROMファイルを直接変更してエクスポート
- 🌐 **多言語対応** - 中国語/英語/日本語インターフェースをシームレスに切り替え
- 📋 **レベル管理** - ドラッグ＆ドロップでの並べ替え、一括編集
- 🛟 **独立バックアップ** - ROMアドレスに依存せず、単一ステージまたは全ステージを入出力
- 📦 **下書き・共有タブ** - 下書き、読み込み、共有ステージを独立編集し、正式一覧の末尾へ追加可能
- 📴 **無効ステージ保護** - ステージ数を減らしても末尾データを削除せず、灰色の無効状態で保持

## 📖 使用ガイド

### 1. ROMをアップロード

- 「📁 ROMファイル選択」ボタンをクリック
- 合法的に所有しているモアイくんROMファイル（.nes）を選択
- 読み込みが完了するまで待つ

### 2. レベルを編集

- 左側のサイドバーからレベルを選択
- 右側のツールバーでタイル/スプライト/特殊アイテムを選択
- 左クリックで配置、右クリックで削除
- シーン、ワイドスクリーン、その他のプロパティを調整

#### 鳥とトビウオ（Sprite 12）

- シーン4はトビウオ、その他の対応シーンは鳥になります。シーン7・8には未対応です。主人公と同じパレットを使い、横に移動して障害物に当たると折り返します。主人公は上に乗って移動できます。
- 上から頭に着地すると半マス（8ピクセル）滑らかに下降し、約90フレーム後に半マス上昇します。上昇する前にもう一度ジャンプして着地すると、さらに半マス下降して合計1マス低い位置を保ちます。その後も2回の着地ごとに1マス下げられます。最下段からはさらに半マスまで下降できますが、踏み続けても次の1段には進まず、元の上昇待ち時間も延長されません。乗り続けるだけでは再び下降せず、上／下キーによる昇降はできません。
- 左右は自動で巡回し、左右キーは主人公の歩行だけを操作します。通常どおりジャンプしたり、端から歩いて離れたりできます。上下移動では地形と主人公の頭上を確認し、障害物があると停止します。地面に下降を阻まれると未完了の下降は取り消され、何度踏んでも崖を離れてからまとめて下降することはありません。
- Tile 13を叩くと、通常のモンスターは従来どおり弱体化します。鳥とトビウオは代わりに1マス上昇してその高さを保ち、叩いた瞬間の主人公から離れる方向へ飛びます。すでに離れる向きの場合、同じ横位置の場合、ループするマップの両側が等距離の場合は向きを保ちます。天井の判定は有効ですが、画面上端から飛び出せます。完全に画面外へ出ると消え、原作の待ち時間と煙のアニメーションを経て出現位置に復活します。出現中や死亡中は叩いても反応しません。
- 驚いた際の横方向の加速は上昇中だけ続き、目標の高さに着くとすぐ通常の毎更新0.5ピクセルに戻ります。天井に阻まれた場合や、踏まれて上昇が中断された場合も通常速度に戻ります。叩いた瞬間の横方向の最短距離に応じて、32ピクセル未満は毎更新2ピクセル、32～63は1.5、64～95は1、96以上は0.5で飛びます。再び叩くと速度を再計算してさらに1マス上昇し、復活時には驚き状態を解除します。
- 接触しても主人公はダメージを受けません。頭突き、投げた石、落下するブロックや石、爆発には通常のモンスターと同じ被弾・死亡ルールが適用され、原作のカウントダウン後に出現位置で復活します。初回出現と復活の際は通常のモンスターと同じ煙のアニメーションが流れ、終了後に飛び始め、主人公が乗れるようになります。

#### ポータル試作（Sprite 13）

- Sprite 13 は1マス・16×16ピクセルです。『クルクルランド』の4コマと、それを縮小した移行用2コマを予約済みCHR `$C0–$FB` に格納します。既存の画像は維持されます。
- 通常は背景で描画し、ハードウェアスプライトを非表示にします。石などのタイルや落下物が重なった時だけ、2枚の8×16スプライトで門を補います。障害物が離れると背景へ戻ります。両方式はシーン既存の色を使い、衝突マップを変更しません。通常は8ゲーム更新ごとにコマが進み、混雑時は背景更新を順番に処理します。
- 各レベル8個のオブジェクト枠を1個使用します。ポーズ中は時間を停止し、背景の門は残ります。補画スプライトは通常の敵と同様に非表示になります。遮られた門が同じ高さに集中すると、FCの1走査線8スプライト制限でちらつく場合があります。
- 同じ番号の2個がペアになります。配置済みの門を再クリックすると1〜4の番号が切り替わります。A/Bを表示し、赤い？はペア未成立です。最初に置いたAが入口です。同じ組は共通の配色を使い、門の隅に1〜4の番号を常時表示します。組ごとにシーン既存の色を割り当てますが、似た色や背景と補画の近似色もあるため、番号で確実に識別できます。
- 300ゲーム更新（約5秒）ごとに出入口が入れ替わり、入口は順再生します。出口には静止した外枠と組番号だけが表示され、透明な内側から運ばれた物が見えます。最後の約1秒は入口が「縮小・停止・拡大」の移行となり、両端の転送を停止します。主人公は入口の中心付近で自動転送され、出口に留まれば次の切替後に自動で戻れます。
- 転送が成功すると、入口で原作の敵が消えるアニメーションの最後の3コマを16ゲーム更新で再生します。主人公の転送時は、その間にカメラが出口へ移動します。
- 壁や救助対象を含む全15種のタイル、活動中の敵、飛び道具、爆弾を転送できます。落下タイルはマスに揃った時に転送し、着地点で落下判定を再開します。出口が塞がっている場合は待機します。火を吐く像とゴールは固定です。2×2マスのゴールとポータルの間は1マス以上空けます。旧ステージで重なっている場合はポータルを優先表示します。

### 3. レベルをテスト

- 「🎮 ステージテスト」をクリックして、エミュレータで現在のレベルを実行
- 「🎮 ROMテスト」をクリックして、完全なゲームをテスト
- テスト・ダウンロードはすべて拡張 Mapper 2 ROM（PRG 128 KiB）を使用します。アップロード元のファイルは変更しません。
- 「一時停止中に上キーで視点切替」は初期状態でオフの実験機能です。オフでは単画面固定・横長画面ループ追従を維持します。オンでは単画面固定・横長画面の原版境界停止から開始し、一時停止中に上キーでループ追従へ切り替えます。切替は1フレーム最大4ピクセル。横長画面の一時停止中の左右閲覧は常に使用でき、単画面ではループ追従時のみ使用できます。コウモリの横方向ループもこの設定に従います。
- 原版の `START / CONTINUE` とパスワード機能を復元しました。ステージテストは `START` を選び、視点切替が有効な場合は一時停止中に上キーで切り替えます。
- この設定がオンの場合、ステージ開始時と一時停止中の閲覧から戻るときも、1フレーム最大4ピクセルで滑らかに目標へ移動します。
- 一時停止中は主人公と背景として描かれる敵を残し、ほかの敵を非表示にして、敵のスプライト画像領域に `PAUSED` と方向アイコンを表示します。`PAUSED` は常時表示し、方向アイコンだけがゆっくり点滅します。画面の左右端にある矢印で左右の閲覧を案内し、視点切替が有効な場合は点滅する上方向アイコンと常時表示の `LOOP ON/OFF` を同じ行に表示します。左右の閲覧を始めると操作ヒントは消えますが、`PAUSED` は表示を続けます。次の一時停止、または上キーで視点を切り替えた際に操作ヒントと最新の状態を再表示します。再開時は敵の画像を復元し、カメラが戻るまでゲームとタイマーを一時停止して、到着後に自動で再開します。移動中のキー入力では途中解除されません。
- 「⏹️ エミュレータ停止」をクリックして、編集に戻る
- ショートカット：`F5` でステージをテスト、`F6` でエミュレータを停止、`Ctrl + S` でステージを保存します。ボタンが無効なときはショートカットも動作しません。

- エミュレータ実行中、`Shift + F1`～`Shift + F4` で4つの一時スロットにセーブし、`F1`～`F4` でロードできます。スロットは上書きできます。空のスロットはロードできません。
- モバイル版では「エミュレータメニュー」の操作リストからクイックセーブ、クイックロード、エミュレータ停止を操作します。メニュー表示中はゲームが一時停止し、閉じると再開します。F1 スロットを使用し、上書き、ロード、停止には確認が必要です。
- 「画面を戻す」を押すと、ゲームを再起動せずに画面を表示位置へ戻し、左右中央に配置します。
- エミュレータを停止するか別のROMを読み込むと、4つのスロットは消去されます。クイックセーブはROMやブラウザのストレージに保存されません。
- F1、F3、F4 はブラウザのショートカットでもあるため、キーの取得はブラウザやOSによって異なります。
- ゲームのセレクトキーは `Alt` で、`Shift + F1`～`Shift + F4` のクイックセーブとは別です。内蔵 jsnes は音声チップの状態を保存しないため、ロード直後の音声が一時的に途切れる場合があります。

### 4. 保存と共有

- 新しいブラウザキャッシュは、旧キャッシュを削除せずROM・ステージ・下書きを一度コピーします。ROM内部より新しい個別ステージキャッシュを優先します。
- 編集済みROMはバージョン記録と局所的なパッチ・配置の特徴で判定し、ファイル全体のハッシュは使用しません。互換性のある画像差替版も使用できます。新版・旧版の出力や版不明の拡張ROMを再読み込みした場合、赤い警告を表示したまま編集・テスト・エクスポートを継続できます。バージョン記録は再パッチの安全性を保証しません。
- 全ステージをバックアップしてから「未編集ROMに交換・ステージ保持」を使用してください。順序・数・敵・下書き・未保存の編集・設定を保持します。検証やキャッシュ保存に失敗しても、旧プロジェクトは保持されます。

- **💾 ステージ保存** - 変更をメモリに保存
- **📝 ROMに書き込み** - すべての変更をROMデータに書き込む
- **⬇️ ROMダウンロード** - 変更されたROMファイルをダウンロード
- **🔗 ステージ共有** - 共有リンクを生成し、友達にコピーして送信
- **📤 現在のステージを書き出す** - 未保存の変更を含む現在の編集を `.moailevel` で保存
- **🧰 全ステージを書き出す** - 正式ステージと下書きを `.moaipack` 復旧ファイルで保存
- **📥 ステージを読み込む** - 単一ステージは下書きへ、全ステージパックは正式ステージを復元
- **🧰 全下書きを書き出す** - 下書き・共有ステージを `.moaidrafts` で個別に保存
- **➕ 正式ステージに追加** - 有効ステージの末尾、灰色の無効ステージより前に下書きを挿入
